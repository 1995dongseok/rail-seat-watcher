신규 가입자는 기본 거부 상태입니다. 허용해야 기차·공연 조회와 감시를 쓸 수 있습니다. 코레일 계정은 기차 조회에만 필요하고, 공연(NOL 티켓)은 계정 없이 조회됩니다. 텔레그램은 사용자가 봇에게 연결 코드를 보내면 자동으로 연결되며, 필요하면 여기서 chat_id 를 직접 고칠 수 있습니다.

항공 조회는 별도 허용이 필요합니다. 사용자 표에서 전체 사용과 ✈ 항공 사용을 모두 허용하세요. 관리자는 항상 사용할 수 있습니다.

외부 호출 부하 서버 IP 하나에서 나가는 호출입니다. 활성 감시가 각자 주기로 돌 때의 예상값이며, 상한을 넘으면 주기를 늘리거나 감시 상한을 줄이세요.
